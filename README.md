# 🧠 WellMind – Plataforma de Bem-Estar Inteligente

WellMind é uma plataforma inteligente de autocuidado que utiliza Inteligência Artificial generativa para analisar diariamente dados sobre sono, humor, hidratação, alimentação, foco, estresse e bem-estar geral. A aplicação fornece *feedbacks* personalizados, auxiliando o usuário na construção de uma rotina mais saudável e equilibrada.

---

## 📌 Status do Projeto

> **Status:** Concluído ✅

---

## 📚 Sobre o Projeto

A **WellMind** foi criada para auxiliar pessoas no desenvolvimento de hábitos saudáveis por meio de um questionário diário simples. As respostas são enviadas para um modelo de IA que realiza uma análise contextual e gera recomendações personalizadas para otimizar o sono, humor, hidratação e demais indicadores de qualidade de vida.

---

## 🛠 Tecnologias Utilizadas

- **Frontend:** React, Vite, TypeScript, Tailwind/CSS
- **Backend:** Java, Quarkus
- **Banco de Dados:** Oracle SQL (Developer e Data Modeler)
- **Hospedagem & Deploy:** Vercel (Frontend), Render (Backend)
- **Versionamento:** Git e GitHub

## ⚙ Instalação e Execução

### Pré-requisitos
- [Node.js](https://nodejs.org/) instalado (versão LTS recomendada)
- [Git](https://git-scm.com/) instalado

### Passo a passo

```bash
# 1. Clone o repositório
git clone https://github.com/WellMind-Bem-estar-Inteligente/WellMind.git

# 2. Acesse a pasta do projeto
cd WellMind

# 3. Instale as dependências
npm install

# 4. Inicie o servidor de desenvolvimento (Vite)
npm run dev
